# CSP-Portfolio
Python code from AP CSP

Welcome to my Python development portfolio! This repository showcases a diverse collection of fundamental programming projects, text-based games, and functional scripts designed to solve logic problems and automate tasks. Through these projects, I demonstrate core software engineering concepts including object-oriented programming, data structure manipulation, algorithm design, and interactive user interfaces.


🚀 Key Project Highlights
Games & Simulations: Interactive applications including Rock-Paper-Scissors (rps.py), a casino-style simulator (slot.py), custom gameplay mechanics (game.py), and logic-driven scenarios (simulation.py).
Utility & Productivity Tools: Practical scripts for daily tasks, featuring a functional calculator (calculator.py), an ATM banking simulator (atm.py), a task manager (todo.py), and a shopping tracker (grocery.py).
Text Processing & Linguistics: Creative automation tools handling string manipulation, such as Mad Libs (madlibs.py), text transformation (playback.py), text-to-emoji converters (faces.py), and headline generators (clickbait.py).

Algorithms & Logic: Core algorithmic implementations focused on optimization, including finding maximum values (largest.py), peak elements (peak.py), mathematical parity (parity.py), and numerical tracking (counter.py).

🛠️ Core Skills Demonstrated
Control Flow: Implementing precise loops, conditionals, and error-handling mechanisms.
Data Management: Organizing, parsing, and storing dynamic user input efficiently.
Object-Oriented Programming: Building modular and reusable code structures using classes
Image Processing: Basic manipulation and handling of visual assets
